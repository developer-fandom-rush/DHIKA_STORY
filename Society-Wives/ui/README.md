# Society Wives — Story and Plot UI

The public reader is built from `ui/src` and deployed to `/DHIKA_STORY/Society-Wives/`.

- **Reading:** choose Episode 01, 02 or 03 and read the saved story/prose by scene.
- **Planning:** Episode 04A (evening) and 04B (next day), character-wise plots only.
- Original story/prose and plot JSON files remain in the Society-Wives source archive. No approval locks, galleries, image thumbnails or old episode planning panels are displayed.
- Selected character reference portraits remain in `../assets/` for future use; the reader does not request or display any images.
- The Dhika reader remains separate and unchanged.

Build from `Society-Wives/ui` with `npm install && npm run test && npm run build`.
