# Society Wives — Five Veils of Desire

## NEW, INDEPENDENT UNIVERSE

This directory is the new Society Wives story universe. It does **not** inherit the characters, professions, spouses, episode chronology, or character relationships from the older `Society_Story` project or its Drive archives. Those are out-of-scope reference archives, not canon for this story.

Dhika is a separate fiction. The *technique* of slow-burn interactions, contrasting viewpoints, recurring ordinary encounters and mini-arcs may be discussed, but **Dhika characters, events and continuity do not exist in Society Wives**.

- Five personal society/home environments

These are **11 narrative lanes**, not eleven predetermined romances.

- `episode-01.html` and `episode-01.json`: new independent EP01, currently **DRAFT FOR REVIEW**.

- `arc-planner.html` / `arcs.json`: proposals, not approved episode prose.

- Children appear in family contexts only, never attraction routes.
- Existing archived Drive or GitHub originals have **not been physically deleted**; this project's canon simply excludes them.
